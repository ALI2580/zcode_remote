# TalkBack 深检与单手热区真人评估执行手册

状态：待真人执行（两台可用设备均无屏幕阅读器，见 BLOCKERS）
编制：mobile-portrait-ux 专项（2026-09-15）
预计用时：TalkBack 深检约 30 分钟 + 单手热区评估约 15 分钟

## 0. 你需要

- 一台实体 Android 手机（任意品牌），已安装 Google TalkBack
  （Play 商店或系统「设置 → 无障碍 → TalkBack」；小米/华为等国产 ROM
  需登录后从应用商店装「Android Accessibility Suite」）。
- ZcodeRemote .qa 包（构建命令见 §1）。
- 结果直接记录在本文末尾 §5 模板里（填空即可）。

语义信息面已由自动化守护（`test/ui/mobile/semantics_walk_test.dart`：
tooltip/button/selected/树序），你只需要评估**焦点行为与手感**，
不需要核对每个控件的文字标签。

## 1. 准备

```bash
# .qa 包构建（主目录或 worktree 均可）
flutter build apk --release --dart-define=ZCODE_ANDROID_QA=true
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

- 手机开启 TalkBack：设置 → 无障碍 → TalkBack → 开启（会弹出教程，
  划动 = 移动焦点，双击 = 激活，两指滚动 = 列表滚动）。
- 打开 ZcodeRemote .qa，使用假服务数据（QA 包自带合成环境）。

## 2. TalkBack 深检场景（按序执行，每项记 通过/问题）

| # | 场景 | 操作 | 评估点 |
| --- | --- | --- | --- |
| T1 | 聊天顶栏 | 线性划动从顶栏开始遍历 | 焦点顺序与视觉顺序一致；每个钮有名字（如「切换终端」）而非只读「按钮」 |
| T2 | 任务抽屉 | 开抽屉逐项划动 | 任务名可朗读；「更多」菜单项朗读含激活状态（如「切换终端（已打开）」） |
| T3 | 模型选择 sheet | Composer 打开模型面板 | 每行朗读「XXX，按钮」；选中行含「已选中」；禁用行不可激活且播报禁用 |
| T4 | 设置 列表→详情 | 设置 → 选分类 → Back | 列表行可朗读；进入详情后焦点落在详情顶部而非页尾；Back 回列表焦点不丢 |
| T5 | 终端抽屉 | 开终端抽屉 + 最大化 | 标签/关闭/最大化钮焦点可达（均为 48dp）；关闭后焦点回到打开钮 |
| T6 | 大字 200% | 系统字体调 200% + TalkBack | T1–T5 无焦点矩形溢出屏幕、无重叠 |

## 3. 单手热区主观评估（右手单手握持，拇指操作）

依次做 6 个主流程，凭手感只打分（1=很别扭，5=顺手）并记误触：

| # | 流程 | 打分 | 误触/够不到 |
| --- | --- | --- | --- |
| H1 | 开抽屉切任务再返回 | | |
| H2 | 输入文字 → 点模型 → 选择 → 发送 | | |
| H3 | 长按消息 → 复制 | | |
| H4 | 打开 diff → 返回 | | |
| H5 | 设置改一项失败重试 → 返回 | | |
| H6 | 开终端 → 输入 → 关闭抽屉 | | |

客观对照（不需要你做）：发送钮/终端抽屉/最大化钮已由 rect 断言确认
位于屏幕下半拇指区，顶部仅有导航与「更多」（系统惯例位）。

## 4. 常见问题怎么记

- 焦点跳到屏幕外/重叠：记场景号 + 手机型号 + 复现步骤。
- 某控件读不出名字：记场景号 + 控件位置（截图更好）。
- 手感 <3 分的流程：记具体哪一步别扭（够不到/要换手/怕误触）。
