# ZcodeRemote 设计草稿 V2

日期：2026-09-08。性质：交互与响应式设计提案，尚未实现生产功能。

**实施更新（2026-09-08）**：Flutter 主工作界面、底部设备/头像菜单、客户端设置、五形态布局和阅读状态恢复已接入产品入口；当前完成与待迁移范围见 [V2 实施记录](v2-implementation.md)。本文的完整功能清单仍是目标，不代表终端、全量官方设置等能力已经完成。

**最新技术决策：上述布局由 Flutter 原生实现，Android 作为主要交付平台。** 五种形态、官方任务栏、头像菜单、全量官方设置与客户端扩展的设计目标保留；下文 Web 宿主相关文字只记录历史方案。

后续已确认：头像和名字整体点击弹出官方小菜单；设置中心保留官方 Web 的全部设置内容和能力门控。V2 预览中的五个客户端分组是扩展区域，不能替代官方设置。官方源码清单见 [official-settings-catalog.json](official-settings-catalog.json)，首个实际运行验证实现见 [../web_client/README.md](../web_client/README.md)。

本稿接受上一轮的 Web 核心 + Android 宿主方向，并覆盖上一稿关于顶部设备选择、设备返回和主题快捷按钮的设计。聊天页顶部按官方 Web 的任务信息和工具入口组织。

## 1. 信息层级

```text
左侧导航                       官方任务栏
  新建任务 / 搜索              [导航] 任务标题 · 项目 · 分支 · 更多    终端 / 右面板
  项目与任务列表
                             对话区                       右侧工作面板
                             官方消息/工具/状态            审查 / 终端 / 辅助会话
                             composer + 可选麦克风
  当前设备 ▾
  用户信息             设置
```

- 删除上一稿聊天 header 中的「设备返回」、顶部中间设备选择、右上主题切换。
- 顶部只呈现当前任务信息与官方工作入口。窄屏的左按钮是导航抽屉开关，不是返回设备首页。
- 设备切换收进左栏底部的独立一行，位于用户信息与设置上方；展开一个向上的设备菜单。
- 设置入口在左栏底部。手机和折叠外屏先打开导航抽屉，再进入设置或切换设备。
- 右上角保留终端与右面板入口；右面板内使用「审查 / 终端 / 辅助会话」切换。
- 帮助、分支等在窄屏的收纳方式属于待官方手机截图校准项，不把本稿推断标成已完成的像素复刻。

设备切换后展示一次短提示确认目标，并恢复目标设备的任务。不得把来源设备的草稿、模型设置或辅助会话带过去。

## 2. 五种屏幕形态

以下数值是草稿预览宽度，不是某款机器的硬件像素，也不是最终硬编码断点。产品依据实际逻辑宽度、文字缩放、输入方式、键盘和可用高度布局。

| 形态 | 草稿示例宽度 | 默认工作布局 | 打开右面板 | 导航和设置 |
| --- | --- | --- | --- | --- |
| 普通手机窄屏 | 390 | 单列对话，任务栏紧凑 | 覆盖工作区，提供关闭入口 | 左侧导航抽屉；设置铺满工作区 |
| 折叠手机折叠态 | 344 | 更窄单列，标题省略，composer chips 优先图标 | 覆盖工作区，不压缩成双栏 | 同手机；侧栏不横向溢出 |
| 折叠手机展开态 | 720 | 默认左栏 + 对话；可手动收左栏 | 打开右面板时暂收左栏，保留对话 + 面板 | 面板关闭恢复之前的左栏偏好 |
| 平板竖屏 | 834 | 左栏 + 对话，正文宽度受控 | 对话 + 面板优先，空间不足暂收左栏 | 设置采用分类 + 内容，空间不足转单列 |
| 平板横屏 | 1024 及以上 | 左栏 + 对话；右侧按需打开 | 在可读宽度足够时三栏同时存在 | 设置可居中展现分类与内容 |

### 布局约束

- 布局算法先确保内容最小可读宽度，再决定常驻侧栏数量；不只判断「横屏/竖屏」或 Android 设备类别。
- 提案起点：左栏约 208–248，右栏约 288–360，对话可用宽度不足约 360–400 时退回覆盖式面板；这些值须用实际字体和大字号验收修订。
- 大字号降低可容纳栏数，优先收起辅助栏，不缩小用户选定的字体。
- composer 用自身容器宽控制 chips 展开，沿用官方能力边界进行验证；不可用整个屏幕宽度代替。
- 多窗口/分屏/浮窗使用同一逻辑，不另写设备型号分支。
- 存在物理铰链遮挡时，利用宿主提供的显示区域信息避让；不能仅从宽高比推断铰链。

### 折叠、旋转、键盘与恢复

1. 折叠/展开/旋转只重排视图，设备 runtime、bridge 和订阅保持同一生命周期。
2. 保留 taskId、辅助 sessionId、草稿、未发送附件、选中面板 tab 和滚动消息锚点；不只保存绝对像素偏移。
3. 若展开态打开右面板后折叠，右面板转覆盖式；关闭后回到同一对话位置。
4. 左右抽屉不在手机上同时盖住对话；系统返回按弹层 → 工作面板/导航 → 页面顺序处理。
5. 键盘升起时 composer 随可视区域上移，消息可用高度缩小；不重复叠加 safe-area 与键盘底距。
6. 文字变化或旋转不能把正在阅读历史的用户拉到最新消息；只有用户启用的跟随状态驱动自动滚动。

## 3. 设备入口和管理

首次无设备时仍保留干净的设备添加页。连接后默认进入上次工作任务，正常工作时不反复经过设备首页。

左栏底部设备行显示：设备名、真实连接状态、下拉指示。菜单列出设备、当前勾选和状态；末尾为「管理设备」。

设置中心的设备管理提供添加、重命名、更新连接凭据、连接/断开、移除和最近工作位置。设备本地 id 与配对凭据分离。切换与管理使用同一份 DeviceRegistry。

## 4. 设置中心

设置中心延续官方设置入口，把当前客户端和远程桌面设置清楚分组。以下是新增客户端能力范围，不能无意同步覆盖另一台桌面的设置。

| 分组 | 内容 | 作用域 |
| --- | --- | --- |
| 通用 | 界面语言：跟随系统/简体中文/English | 当前客户端 |
| 外观 | 主题：跟随系统/深色/浅色；文字缩放；代码字号；实时预览/恢复默认 | 当前客户端 |
| 离线语音 | 模型目录、下载、启用、删除、识别语言、资源状态 | 当前客户端安装环境 |
| 设备 | 已保存设备、凭据更新、重命名、断开/移除 | 当前客户端 |
| 更新与关于 | 当前版本、稳定/Beta 通道、检查更新、下载/校验/安装、更新说明 | 当前客户端应用 |
| 远程桌面设置 | 官方原有模型供应商、插件等入口，按已连接设备和官方能力提供 | 当前所选桌面 |

默认主题与字号以官方基线对齐；修改文字大小属于用户主动选择的差异。视觉验收需要同时覆盖默认和大字号，不能把自定义后的画面称作默认像素一致。

界面语言不翻译历史消息、代码和任务内容。系统字号与应用字号应合成一次，避免重复缩放；下限不覆盖系统无障碍要求。

## 5. 延续 Zemote 的更新能力

- 迁移并测试现有版本比较、稳定/Beta 通道、Release 资产选择、Android ABI 匹配、下载/完整性校验和安装交接。
- 更新请求指向 ZcodeRemote 自己的发布源，版本常量和发布测试同步维护。
- 状态完整：未检查/检查中/已最新/可更新/检查失败/下载中/校验失败/待安装。
- 检查失败不显示成「已是最新版本」；下载不中断当前设备会话。
- 用户数据迁移与覆盖安装保持兼容；签名一致，不依赖先卸载再安装。
- Web 版的版本检查走前端发行版本与资源更新策略，不显示 APK 安装流程；有新前端版本时提示可刷新，先保存草稿再更新。

本轮只定义交互，不查询真实发布版本、不下载安装包。示意内的更新状态均为模拟。

## 6. 延续 Zemote 的离线语音

旧仓库已有模型目录、平台条件实现、下载与 sherpa-onnx 识别逻辑，可迁移能力和测试，不能只把模型名称复制进设置页。

- 初始目录可沿用现有 SenseVoice Small、Zipformer CTC、FireRed ASR、Whisper Tiny 等配置；实际可用模型、文件大小和校验值来自经过验证的目录，不硬编造下载体积。
- Android 在本机下载、加载和识别；识别结果填入 composer，默认不自动发送。
- 麦克风入口位于 composer 左侧动作组；使用前检查模型/权限，未安装模型时进入设置中心的语音分组。
- 录音、识别中、结果待确认、取消/失败都有可见反馈。取消不丢原草稿；插入时绑定录音开始时的 device/workspace/session，切设备后不得插入新设备草稿。
- 模型设置、音频权限和本地缓存属于手机/浏览器客户端，切桌面设备不要求再次下载同一个模型。
- 下载/校验/解压/加载分阶段反馈；下载中断和磁盘不足可以重试，不能把半成品标成可用。
- 大模型下载前展示实际空间需求与语言支持；启用失败保持上个可用模型状态。

**已核对的 Web 特殊情况**：旧 `voice_model_store_web.dart` 的模型字节存在静态内存 Map，刷新后丢失。新版本须设计浏览器持久缓存、空间额度不足和缓存被回收的恢复流程，并验证浏览器识别运行时；不能把旧实现直接视作刷新后仍可离线使用。原生和 Web 的支持状态如实呈现。

## 7. 右侧工作面板

- 审查：文件变化列表、文件 diff、当前文件导航；长代码区域可独立横向滚动，正文不跟随溢出。
- 终端：会话/终端选择、输出、输入，区分只读输出和可执行命令；仅在真实协议能力支持时提供输入。
- 辅助会话：独立 sessionId 与草稿，上下文来源可见；遵循官方禁用嵌套、编辑重发、分叉等门控。
- 切换 tab 不关闭另一 tab 的运行状态。当前所选 tab 按 device/workspace/session 作用域保存。
- 点击顶栏终端直接选中终端 tab；点击面板开关恢复上次 tab。
- 折叠展开改变摆放方式，不重新创建辅助会话、不自动重发命令。

- 形态切换控件在预览外部，不会出现在正式应用里。
